# 🐒 Monke Study — Gamified Focus Timer

A minimalist, gamified productivity tool built for deep work sessions. Earn coins, level up XP, and unlock aesthetic themes while staying focused!

## 🚀 Features
- **Focus Timer**: Focus mode (25m), Short Break (5m), &amp; Long Break (15m).
- **Gamification System**: Earn **Coins 🪙** and **XP ⭐** for every completed session.
- **Monke Shop**: Spend coins to unlock animated themes (Lofi Night, Cyberpunk Neon, Deep Forest).
- **Cloud Sync**: Connected with Supabase PostgreSQL database.
- **Offline First**: Saves your progress locally via Browser LocalStorage.

## 🛠️ Tech Stack
- **Frontend**: HTML5, Tailwind CSS, Vanilla JS
- **Backend &amp; Database**: Supabase (PostgreSQL)
- **Hosting**: GitHub Pages
